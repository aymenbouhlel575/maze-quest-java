# Roadmap

## V1 — shipped in this repository

- [x] Desktop Java Swing interface
- [x] Randomized DFS maze generation
- [x] Player movement and collisions
- [x] Eight collectibles and exit victory condition
- [x] A* visual hint
- [x] Timer, moves, pause and restart
- [x] Headless logic tests and build scripts
- [x] Architecture and game-design documentation

## V2 — proposed

- [ ] Main menu and settings
- [ ] Difficulty presets and multiple tile layouts
- [ ] Sounds, animations and sprite assets
- [ ] Keyboard remapping and accessibility improvements
- [ ] Dedicated game-over/next-level screens

## V3 — proposed

- [ ] Enemies using different pursuit strategies
- [ ] Score persistence, saved runs and achievements
- [ ] Optional multiplayer (requires separate design)
- [ ] Advanced algorithms comparison (BFS, Dijkstra, A*)

Feature status is intentionally explicit: unchecked items are not implemented.
